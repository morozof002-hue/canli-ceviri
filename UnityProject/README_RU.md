# NEON COAST — Unity 3D foundation

Отдельный Unity 6 проект, не WebView и не HTML-игра.

## Требования
- Unity 6.0 (6000.0.x), Android Build Support, SDK/NDK и OpenJDK.
- URP, Input System, TextMeshPro, AI Navigation (пакеты подключены в manifest).
- Android: ARM64, IL2CPP, минимум API 26.

## Создание сцены
1. Открой папку `UnityProject` через Unity Hub и дождись импорта.
2. Выбери **NEON COAST → Build First 3D District**.
3. Открой `Assets/Scenes/NeonCoast_District01.unity`, нажми Play.
4. На ПК: WASD/стрелки, Shift — бег, Space — прыжок. На телефоне — джойстик, SPRINT, JUMP; свайп справа поворачивает камеру.
5. Подойди к машине и нажми ENTER/EXIT, чтобы сесть за руль. В машине управление — тот же джойстик.

## Что есть в этой основе
Процедурный 3D blockout приморского района, улицы, набережная, море, фасады, пальмы, фонари, машины, персонаж и камера. Добавлены базовые физические машины, посадка/высадка, миссионный директор и маркер цели.

## Честный статус
Это исходный Unity-проект и генератор сцены. Он ещё не запускался в Unity и не собран в APK; модели и анимации пока блокинговые. Перед релизом необходимы проверка компиляции, визуальная настройка URP, тест производительности и сборка Android на реальном устройстве.
